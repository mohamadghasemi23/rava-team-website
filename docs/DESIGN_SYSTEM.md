# RAVA V1 Design Direction

## Reference
The selected public-site reference is the Modern Agency homepage. RAVA should faithfully adapt its hierarchy, rhythm, project presentation, interactions, sliders/carousels and motion logic rather than inventing a new homepage from scratch.

## Required adaptation
- Persian RTL
- Light-first visual system
- White/off-white main background instead of black
- Deep navy / near-black typography
- RAVA blue as restrained accent
- Minimal Persian typography
- Premium, modern, spacious, not flashy

## Typography
Preferred starting point: Vazirmatn across UI/body/headings unless visual testing proves another Persian font materially better. Estedad may be evaluated for selected headings, but consistency and readability take priority.

## Homepage structure to preserve
- Minimal header
- Hero with availability/status line
- Oversized statement
- Short supporting copy and CTA
- Stats
- Services marquee
- What We Do / numbered services
- Projects presentation
- Secondary projects presentation
- Featured case study
- About / Who We Are
- Values
- Final CTA
- Minimal footer

## Media
Preserve the visually strong image sliders/carousels from the reference where they exist. Their media must be editable and reorderable from admin.

## What admin may change
- Text
- Images/media
- Project selection/order
- Service content/order within approved structure
- Stats
- CTA copy/links
- SEO content

## What admin may NOT change in V1
- Arbitrary page layout
- Component hierarchy
- Grid system
- Motion system
- Drag/drop sections
- Theme architecture

## Admin UI
Admin is not a showcase. It should be Persian RTL, light, minimal, fast and practical with a stable sidebar and little/no decorative motion.
