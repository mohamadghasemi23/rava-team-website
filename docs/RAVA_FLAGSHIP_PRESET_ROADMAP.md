# RAVA Flagship Preset Roadmap

## Status

This document preserves the current owner-reviewed RAVA TEAM flagship design exploration so no concept or delivery decision depends on conversation memory. It is a design record, not implementation proof and not Production authorization.

The shared visual family is **RAVA Digital Atelier**: RAVA itself is the focal product; a semantic page structure becomes a finished responsive site; navigation, Mega Menus and key controls use a coherent optical glass/3D language. Physical architecture imagery is rejected because it misclassifies RAVA as an architecture practice.

## Delivery sequence

Do not implement all four Presets simultaneously.

1. Obtain explicit owner approval for the first implementation composition.
2. Complete D as the foundation: exact Navbar, Mega Menu, typography, optical material, button states, responsive layout, reduced-motion behavior and real RAVA content path.
3. Validate D in private Staging on desktop and mobile; fix material issues and obtain owner acceptance.
4. Extract only proven shared primitives into a versioned Template-family system.
5. Implement A, B and C sequentially as separate versioned Presets using those primitives and each Preset's own composition/rhythm.
6. Run the Template Independence and commercial Gates before catalog release; Presets remain one family and do not count as four independent portfolio Templates.

Parallel implementation is rejected because it multiplies unresolved navigation, typography, accessibility, performance and responsive defects across four surfaces before the foundation is proven.

## Shared implementation contract

- Optical glass/3D Navbar, task-oriented Mega Menu and compact tactile controls.
- Persian Estedad/Vazirmatn and English Manrope/Inter roles.
- No oversized flat blue CTA rectangles.
- No decorative glass over long-form content.
- RAVA product truth in the Hero; no physical-building imagery.
- One primary consultation/project-start conversion.
- CMS-driven, versioned, locale-aware and rollback-safe behavior.
- Complete keyboard, focus, touch, mobile and reduced-motion behavior.
- No fabricated portfolio, clients, testimonials, awards or metrics.
