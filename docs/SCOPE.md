# RAVA V1 Scope

## In scope
### Public website
- Home
- Work / Projects
- Project detail / Case Study
- Services overview
- Web Design & Development
- E-commerce
- Digital Products
- Brand & Content
- AI & Automation
- About
- Contact / Start Project
- Legal/required trust pages as needed
- Future-ready Insights route, not required for initial launch

### Homepage
Faithful adaptation of the selected Modern Agency homepage structure and interactions, including its strong project presentation and image sliders/carousels where applicable.

### Admin
- Dashboard
- Homepage content editing
- Services management
- Projects management
- About content
- Leads / project requests
- Media library
- SEO fields
- Site settings / footer / social links / contact data
- Enamad settings: enable/disable, destination link, logo/code
- Simple preview before publish where practical
- Basic analytics with two simple charts

### Content behavior
Layout and component hierarchy are fixed in code. Text, images, projects, services, stats, CTAs, SEO and selected settings are editable from admin.

## Explicitly out of scope for V1
- Generic page builder
- Drag-and-drop page construction
- Website generator
- Multi-tenant SaaS
- Client website factory
- Arbitrary block system
- Complex revision system
- Heavy audit system
- Scheduled publishing
- Large granular permission matrix
- CRM suite
- Advanced marketing automation
- Full analytics platform

## Future, only if justified later
- English locale
- Insights/blog publishing
- Reusable shared SEO package extracted from RAVA Traffic Engine
- Additional admin roles
- Advanced analytics
- Revisions/audit if operationally needed
