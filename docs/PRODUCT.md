# RAVA TEAM Website V1 — Product Definition

## Goal
Build a premium Persian RTL agency website that generates qualified leads for RAVA TEAM and demonstrates RAVA's ability to design and build digital products.

## Primary commercial focus
1. Web Design
2. Web Development
3. E-commerce
4. Digital Products

## Secondary complementary services
5. Brand & Content
6. AI & Automation

## Positioning
RAVA is an independent digital team. The website must communicate a young, bold, modern and premium identity without looking like a generic web-design agency.

## Core product principle
The website itself must be one of RAVA's strongest portfolio pieces.

## Audience
Persian-speaking businesses and founders who need a website, store, digital product, branding/content support or practical AI/automation work.

## Conversion goal
Primary CTA: شروع پروژه
Secondary CTA: دیدن پروژه‌ها

Primary journey:
Traffic source -> Homepage or Service page -> Project/Case Study -> Start Project -> Lead stored in admin panel.

## Language
V1 is Persian and RTL. Architecture must be ready for a future English version without requiring a redesign.

## Portfolio truthfulness
Real projects are preferred. Up to 2-3 fictional projects may be used to keep the template visually complete, but they must be clearly labeled Concept Project and editable/removable from admin.

## Initial real portfolio material
- RAVA Website — public web project / RAVA's own website
- RAVA Traffic Engine — internal digital product, in development
- Ali Topol Store — e-commerce project, in development
- Ali Topol Content — content/brand work
- Persian Gulf Complex — previous social/content collaboration
- Setareh Fars — previous social/content collaboration

RAVA must be introduced as a team, not as a founder personal brand.
