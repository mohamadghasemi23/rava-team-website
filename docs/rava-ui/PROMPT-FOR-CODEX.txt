ابتدا AGENTS.md را کامل بخوان؛ اگر در Repository وجود ندارد، همین موضوع را صریح گزارش کن و قانون جدیدی از خودت نساز. سپس فایل `docs/rava-ui/CODEX-UI-BRIEF.md` و تصویر `docs/rava-ui/rava-ui-reference.jpg` را بررسی کن.

این تصویر صرفاً Inspiration نیست؛ Visual Target نسخه بعدی UI است. هدف این است که زبان بصری، نسبت‌ها، Hierarchy، RTL، Hero، Feature Grid، Mobile layout و Dashboard تا حد عملی بسیار نزدیک به Reference پیاده شوند، اما متن‌های تصادفی داخل تصویر یا قابلیت‌های غیرواقعی آن کپی نشوند.

RAVA یک پلتفرم فارسی‌اول برای ساخت، مدیریت و توسعه وب‌سایت است. بنابراین Persian/RTL باید از ابتدا بخشی از معماری UI باشد، نه ترجمه‌ی یک UI انگلیسی.

فعلاً هیچ فایل، commit، deploy، migration یا schema را تغییر نده. ابتدا Repository و UI موجود را با Reference و Brief مقایسه کن و به فارسی گزارش بده:
1) چه بخش‌هایی قابل استفاده مجدد هستند
2) چه بخش‌هایی تعارض دارند
3) چه Componentهایی باید اصلاح یا ساخته شوند
4) چه Route/Pageهایی تحت تأثیر قرار می‌گیرند
5) چه ریسک‌هایی وجود دارد
6) Migration/Implementation Plan مرحله‌ای چیست
7) برای رسیدن به شباهت بصری بالا چه چیزهایی هنوز از من لازم داری

بعد از گزارش منتظر تأیید من بمان.
