# RAVA V1 Admin

## Dashboard
Show:
- Visits today
- Visits last 7 days
- Visits last 30 days
- New project/contact requests
- Chart 1: daily visits trend
- Chart 2: top visited pages

## Home editor
Fixed sections only:
- Hero
- Stats
- Services marquee
- Services intro
- About
- Values
- Final CTA

## Services
Manage the six approved services. Editable fields include title, summary, body, order, published state and SEO.

## Projects
Manage real and concept projects. Fields include:
- title
- slug
- project kind: real / concept
- status
- cover
- gallery
- summary/body
- client
- year
- role
- scope
- KPI entries
- featured toggle
- homepage visibility
- order
- SEO

## About
Edit independent About page content, values, stats and CTA.

## Leads
Inbox for contact/project requests.
Statuses:
- new
- in_progress
- replied
- closed
- spam

Display contact fields, service interest, message, source page, timestamp and private internal notes.

## Media
- Upload images
- Preview
- Edit alt text
- Show file dimensions and size
- Replace/remove media safely
- Reorder project gallery media

## SEO
Per page/service/project:
- SEO title
- Meta description
- OG image
- Canonical
- Index/noindex where justified
- Simple search result preview
- Structured data settings only where needed

## Settings
- Logo/brand assets
- Contact email/phone
- Address
- Social links
- Footer links/content
- Enamad enable/disable
- Enamad destination/verification link
- Enamad image/code where technically appropriate

## Permissions
Admin: full content/settings access.
Editor: content/media/projects/services/leads where approved; no security-critical/global configuration changes.

## Preview
Provide a practical preview before publish for editable pages/projects when feasible without creating a separate page-builder architecture.
